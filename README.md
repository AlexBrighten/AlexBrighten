### 💡 About Me

I am a **Product-Minded Full Stack Developer and UX Designer** based in Chennai. 

I spent months mastering pixel-perfect UI design, only to realize that backend architecture is where the real chaos lives. Now, I do both. 

I specialize in building things that automate the boring parts of life—like **JobPulse**, a Manifest V3 Chrome Extension I built to track my job applications so I could spend more time building things instead of filling out forms.
